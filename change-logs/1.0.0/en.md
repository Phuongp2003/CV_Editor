# Changelog (Version 1.0.0)

Hello! This is the initial release of the CV Editor built with Vue 3:

## Key Features
- **Vue 3 Migration:** Migrated the frontend application to Vue 3 and Nuxt UI for faster render times and fluid interactions.
- **Multi-language Support (i18n):** Added built-in interface translations.
- **Realistic Sample CV:** Included a production-ready Software Engineer CV sample as a template.
- **Page Scaling Control:** Implemented font sizing multipliers to easily constrain CV content within a single page PDF.
- **DOCX & HTML Export:** Supported exporting CVs directly as Word documents (.docx) and web pages (.html).
