Fynx CV writer

Plugin viết CV và cover letter dành cho AI agent. Chia sẻ trang này với tester để họ tự cài; không cần gửi file qua chat.

Cài vào ChatGPT web qua GitHub

  1. Workspace admin mở Admin Console → Plugins → Add → Import marketplace.
  2. Nhập Source: https://github.com/Phuongp2003/CV_Editor. Để trống Path và Branch, sau đó authorize GitHub.
  3. Đặt Fynx CV writer thành Available cho workspace hoặc role của tester.
  4. Tester mở Plugins trong ChatGPT web, cài Fynx CV writer, rồi chọn plugin trong composer.

Chỉ admin workspace mới import được marketplace GitHub. Việc này thêm plugin vào workspace, không đưa plugin lên Public Plugins Directory.

Hoặc tải plugin archive

Workspace admin có quyền upload có thể tải gói rồi chọn Admin Console → Plugins → Add → Upload plugin.
