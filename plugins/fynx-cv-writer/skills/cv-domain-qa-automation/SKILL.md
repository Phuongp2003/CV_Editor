# QA automation content DLC

Ask for test level, framework, fixtures, environments, CI trigger, flaky-test controls, defect examples and release decision impact. Distinguish test suite implementation from a measured reduction in defects. Name Playwright, Cypress, Selenium, PyTest or xUnit only when the candidate used them.
