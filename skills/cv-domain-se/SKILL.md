# Software engineering content DLC

Ask which service or product changed, what contract or user path was affected, the candidate's exact contribution, stack, tests, rollout status and observed outcome. Separate source-level implementation from production effect. For backend roles, emphasize APIs, data models, auth and tests; for frontend, user flows, integration and accessibility; for platform, interfaces and operational constraints. Use exact JD terms only when proved.
