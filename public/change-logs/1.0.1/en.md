# Changelog (Version 1.0.1)

Hello! Below are the changes in features, layout, and user experience introduced in version 1.0.1:

## Navigation Bar (Navbar) Layout Changes
- **Workspace Switcher Placement:** The switcher tabs for CV and Cover Letter have been moved to the top left of the header, making it easier to identify and toggle between editors.
- **AI Assistant Menu Experience:** The AI Assistant dropdown list is now displayed in a clean, vertical column, ensuring all role names are fully visible without truncation or clipping.

## Upgraded AI Assistant (Prompt Hub) & New Prompts
- **New AI Assistant Modal:** The legacy prompt helper section has been upgraded into a spacious, full-screen "AI Prompt Hub & Assistant" modal.
- **New Target Roles Prompts:** Added specialized STAR interview prompts for Software Engineers, Business Analysts (BA), Software Quality Control (QC), Product Owners (PO), and a CV Converter prompt to rewrite legacy resume text into standard structures.
- **Gems Link Placement:** Gemini Gems share links and copy actions are now rendered as pill-shaped buttons directly in the sticky header next to the prompt title.
- **Collapsible Playbook Experience:** The playbook instructions are now placed in a dedicated right-hand column. You can toggle this panel to hide or show it with a smooth slide animation, allowing the main prompt viewport to automatically expand and utilize the remaining space. Interactive tabs and link pills automatically hide if a specific role does not contain templates or links.

## Enhanced Preset Management & Data Import
- **Unified Presets Action:** The Load and Save commands are now consolidated into a single "Presets" popover button on the right of the toolbar.
- **Visual Slot Cards Experience:** Opening the presets manager displays a modal grid with 7 slots. In save mode, you can customize the display name, and the text input field automatically focuses and selects all characters on click.
- **Import Button Placement:** The green Import button has been repositioned next to the download button on the toolbar, letting you upload a configuration file or paste JSON data from the AI to restore your CV states immediately.
