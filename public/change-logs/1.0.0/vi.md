# Nhật ký thay đổi (Phiên bản 1.0.0)

Chào bạn! Đây là phiên bản chính thức đầu tiên của CV Editor viết bằng Vue 3:

## Tính năng và Nâng cấp chính
- **Khởi chạy ứng dụng trên Vue 3:** Chuyển đổi toàn bộ nền tảng sang Vue 3 và Nuxt UI giúp cải thiện đáng kể tốc độ tải trang và độ phản hồi.
- **Hỗ trợ đa ngôn ngữ (i18n):** Tích hợp dịch thuật đa ngôn ngữ giao diện.
- **Dữ liệu mẫu thực tế:** Bổ sung mẫu CV Software Engineer hoàn thiện để người dùng dễ dàng tham khảo.
- **Bộ căn chỉnh trang in PDF:** Thêm bộ điều chỉnh kích thước cỡ chữ (size multiplier) giúp tối ưu hóa nội dung CV vừa vặn trong một trang giấy in.
- **Xuất tệp DOCX và HTML:** Hỗ trợ xuất dữ liệu CV sang định dạng tệp Word (.docx) và trang web (.html).
