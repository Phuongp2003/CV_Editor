## Section-Specific Guidelines
- **Experience Bullets**:
  - Start l1 bullets with strong active verbs (Verified, Automated, Detected, Executed, Designed, Prevented, Tested, Checked).
  - **Bolding rule (CRITICAL)**: Bold QA metrics, outcomes, and test suites (e.g., **designed automated API testing framework**, **increased regression test speed by 65%**, **reduced defect escape rate to under 2%**). Do NOT bold tools or framework names in experiences/projects (e.g. do NOT bold **Selenium**, **Playwright**, **Cypress**, **Postman**).
- **Skills**:
  - Group into categories: Testing Methods, Automation Tools & Frameworks, API & Performance Testing, Bug Tracking, Methodologies & Process.
  - Bold 2-3 core skills (e.g., **Automation Testing**, **API Testing**, **Playwright**, **Defect Lifecycle**) to create visual interest.
- **Education**: Omit GPA if it is low or not provided.
